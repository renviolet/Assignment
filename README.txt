WORKWELL - OCCUPATIONAL BURNOUT SELF-ASSESSMENT

How to open:
1. Extract the ZIP file.
2. Open the WorkWell_Project folder.
3. Double-click index.html.
4. The assessment will open in your web browser.

Keep index.html, style.css, and script.js together in the same folder.
No installation or internet connection is required.

Note:
This is an educational awareness tool, not a clinically validated test
and not a medical diagnosis.
